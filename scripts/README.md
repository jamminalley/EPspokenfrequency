# scripts/

The pipeline that builds `out/` from `data/pt.txt.gz`. The top-level
[README](../README.md#how-the-list-is-built) describes what it does; this
file is for running and changing it.

## Running it

```bash
./.venv/bin/python -m scripts.build                 # release build -> out/, reports/
./.venv/bin/python -m scripts.build --stage 1       # April reconstruction -> build/stage1/
./.venv/bin/python -m scripts.build --sample 2000000   # dev run -> build/sample.../
./.venv/bin/python -m scripts.build --set fixes.plural_folding=false   # ablation
```

The release build exits with status 0. It exits 1 if the quality gate
finds a suspect that `config.yaml` does not accept; every output is still
written first.

Each pass is cached in `.cache/` under a digest of the settings that affect
it, so after the first build (about an hour, nearly all of it Stanza) a
change to a later stage reruns in about a minute. Only the release build
writes to `out/` and `reports/`; stage 1 and sample runs go to `build/`,
which is gitignored.

**Stage 1** reconstructs the lost April pipeline with every fix off and
simplemma alone. It reproduces its own earlier output byte for byte, and
the release report compares against it when `build/stage1/` exists.

Other entry points:

| Command | Does |
|---|---|
| `python -m scripts.counts --sample N --top 20` | Pass 1 only; prints the tokenizer fingerprint |
| `python -m scripts.eval_lemmas --backend stanza --backend gated` | Score lemmatizer backends against the gold set |
| `python -m scripts.make_whitelist --suspects reports/quality_suspects.tsv` | Classify quality suspects by the whitelist rule |
| `python -m scripts.make_proper_noun_review` | Merge new proper-noun drops into the review file, keeping decisions |
| `python -m scripts.fit_postag` | Regenerate `data/postag_rules.yaml` from the April release |

## Layout

| Module | Does |
|---|---|
| `build.py` | CLI entry point; runs every step, writes the reports, enforces the gate |
| `config.py` | Loads and validates `config.yaml`; output locations |
| `corpus.py` | Streams the gzip; never decompresses to disk |
| `tokenizer.py` | Artifact stripping, enclitic splitting with stem restoration, sentence starts |
| `counts.py` | Pass 1: parallel unigram counts, fingerprint, cache |
| `bigrams.py` | Pass 2: bigram counts, sampled contexts, capitalization; Dunning G² |
| `lemmas.py` | Backends (simplemma, Stanza, gated, tiered, vote), overrides, closure |
| `occurrence.py` | Per-occurrence splitting of participles and fomos-type forms |
| `conventions.py` | The five conventions of `eval/conventions.md`, plus pronouns |
| `filters.py` | BP list, proper nouns and review decisions, foreign words, fragments, accent folding |
| `postag.py` | The `pos_guess` heuristic |
| `emit.py` | Ranking, per-million, TSV/CSV/Anki writers |
| `quality.py` | Suspect duplicates, the gate, the fold listing |
| `compare.py` | `COMPARISON.md` |
| `eval_lemmas.py` | Gold-set scoring |
| `make_whitelist.py`, `make_proper_noun_review.py`, `fit_postag.py` | Maintenance tools |

Hand-maintained data: `data/lemma_overrides.tsv` (verified lemmatizer
corrections), `data/postag_rules.yaml` (generated by `fit_postag`),
`data/quality_notes.md` (standing notes appended to `QUALITY.md`), and in
`../eval/` the gold set, conventions, gender pairs and proper-noun review.

## Things worth knowing

- **Human decisions live in `eval/`, not in code.** The gold set, the
  gender pairs and the proper-noun review each have a first-pass column and
  a reviewer's column; the reviewer's wins. Regenerating tools merge rather
  than overwrite.
- **`pos_guess` is fitted to the April release** (97.5% self-agreement), so
  it reproduces April's decisions, mistakes included. Stanza's POS tags are
  used internally for splitting, not published.
- **Tried and rejected:** `fixes.cap_sentence_starts`, which excludes
  sentence-initial capitals from the proper-noun evidence. Numbers in
  `reports/QUALITY.md`. The code is kept behind the flag.
- **Stanza is not type-level.** It reads each word in up to five sampled
  sentences, and the majority lemma wins, so its output depends on the
  context sample, which is fixed by digest rather than by a random seed.
